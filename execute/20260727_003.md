TASK: Handle SAP "Invoice already created previously" Response for BC Sync
Please update DeliveriesController.cs in amtemeterai.Api to properly parse SAP's response message when syncing BC Deliveries and prevent duplicate database inserts.

PROBLEM
When syncing a BC delivery where a new BC billing document has not yet been generated in SAP, SAP responds with 200 OK and a payload containing message: "Invoice already created previously" and the existing sapInvoiceNumber.

The controller currently attempts to save this payload as a new invoice, causing PostgreSQL to fail with a unique constraint violation on IX_Invoices_InvoiceNumber during SaveChangesAsync().

REQUIREMENT
In DeliveriesController.cs inside CreateSapInvoice (or the handler processing the SAP response payload):

Check SAP Response Message & Existing DB Record:
Before executing _db.Invoices.AddAsync(...) or _db.SaveChangesAsync(), validate whether:

The SAP response message equals "Invoice already created previously" (or contains "already created"), OR

An invoice with sapInvoiceNumber already exists in _db.Invoices.

Handle Graceful Exit for BC Deliveries:

If either condition is met when processing a BC delivery (type == "BC"), do not attempt to save a new record or invoke SaveChangesAsync() for the invoice entity.

Return a 400 Bad Request or 422 Unprocessable Entity with a clear, user-friendly message explaining that BC billing must be created in SAP first.

IMPLEMENTATION CODE
C#
// Example check after receiving SAP response payload

bool isAlreadyCreatedInSap = sapResponse?.Message != null && 
    sapResponse.Message.Contains("already created", StringComparison.OrdinalIgnoreCase);

var existingInvoiceInDb = await _db.Invoices
    .AnyAsync(i => i.InvoiceNumber == sapResponse.SapInvoiceNumber);

if (delivery.Type == DeliveryHeader.DeliveryType.BC && (isAlreadyCreatedInSap || existingInvoiceInDb))
{
    _logger.LogInformation("BC Sync skipped for Delivery {DeliveryNumber}: No new BC billing created in SAP yet.", deliveryNumber);

    return BadRequest(new
    {
        success = false,
        message = "No new BC Billing document found in SAP. Please create the BC Billing in SAP first before syncing."
    });
}
ACCEPTANCE CRITERIA
Receiving an SAP payload with message: "Invoice already created previously" for a BC delivery returns a clean 400 error response with the user message "No new BC Billing document found in SAP. Please create the BC Billing in SAP first before syncing."

Eliminates DbUpdateException and IX_Invoices_InvoiceNumber Postgres duplicate key exceptions.

Activity logging accurately records the event without rolling back context transactions.
