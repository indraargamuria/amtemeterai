# Taste / Preferences

## Documentation & Communication
- When documenting developed functionality, prefers exhaustive, feature-by-feature detail organized per page/menu (e.g., "in the delivery detail page: feature that displays sales person, feature that displays map location, feature that displays dynamic line..."), rather than high-level summaries. Small UI features count. Confidence: 0.8
- Prefers functionality documentation/deliverables to be split into work packages (e.g., WP1 = delivery, WP2 = invoice/billing) instead of one flat list. Confidence: 0.6
